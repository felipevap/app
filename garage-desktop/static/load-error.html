Não foi possível carregar o site

O endereço configurado não respondeu ou recusou a ligação. Isto é comum se:

  • o servidor Next não está a correr (por exemplo http://localhost:3000 sem npm run dev);
  • o URL está errado ou o site ainda não foi publicado;
  • há firewall ou rede a bloquear.

No menu Arquivo → Definir URL do site… pode corrigir o endereço e tentar de novo.
